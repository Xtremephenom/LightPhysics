The official FFmpeg download page states that FFmpeg publishes source code and links BtbN for 64-bit static Linux builds and Windows executable builds. The selected release-tagged BtbN artifacts are the LGPL static variant built from the FFmpeg 9.0.2 release branch at `n9.0.2-28-g669f5ab083`: Linux x86_64 `ffmpeg-n9.0.2-28-g669f5ab083-linux64-lgpl-9.0.tar.xz` with SHA-256 `b2ee4166aa1f068ac261cbdb637667f789c58f3556b463c41221ca8d971ac793`, and Windows x86_64 `ffmpeg-n9.0.2-28-g669f5ab083-win64-lgpl-9.0.zip` with SHA-256 `7f4cbda0ece7721488eeebf2fa69762d7388bca69450fd13045b408744457b14`. The BtbN build documentation distinguishes the `lgpl` variant from GPL-only dependencies. FFmpeg's legal page states that the project is LGPL 2.1-or-later with optional GPL components; the selected binary's upstream terms do not choose LightPhysics' project license.
