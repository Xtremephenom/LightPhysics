The official 0.13.1 release identifies the x86_64 Linux artifact `uv-x86_64-unknown-linux-gnu.tar.gz` with SHA-256 `eadd9d27c134ab5ac1ffd4473b97a741407f3ea238288f03121fc4deddf90220`, and the x86_64 Windows artifact `uv-x86_64-pc-windows-msvc.zip` with SHA-256 `3b2661a463a5baea7f5076ea2b25ab71d77f36a6c0d809e5350651792f80a672`. The release also publishes attestation guidance. On 2026-10-19, the committed installer verified and installed the Linux x64 tar.gz in the Dockerfile's pinned Node base-image container, preserved the executable bits, and `uv --version` returned `uv 0.13.1 (x86_64-unknown-linux-gnu)`. It also verified and installed the Windows x64 ZIP, preserved the binary, and `uv --version` returned `uv 0.13.1 (62faed335 2026-10-13 x86_64-pc-windows-msvc)`. The measured runtime boundary is limited to these two binary version smokes; Python environment behavior and other profiles remain unqualified.
