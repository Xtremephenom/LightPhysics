The official LTS page identifies Blender 5.2 LTS and patch 5.2.2. The official checksum file lists `blender-5.2.2-linux-x64.tar.xz` as `84098912789dc450e95697c4184fb8a90acbe5111c2ba4aede3fecb57806a168` and `blender-5.2.2-windows-x64.zip` as `3849d17a682cba006075aaa3f3597ecb5c9c30ec31035b2e092c53e40679b535`. The official manual documents command-line operation. On 2026-10-19, the committed installer verified and installed the Windows x64 ZIP with explicit bounded archive, entry-count, per-entry, and total-output limits; the real `blender.exe --background --factory-startup --disable-autoexec --python-expr` command returned `LIGHTPHYSICS_BLENDER_SMOKE_PASS` and exited 0. It then verified and installed the Linux x64 tar.xz in the pinned Docker base image, consumed GNU long-name records, created validated relative symlinks after regular files were staged, and the same background command returned the smoke marker and exited 0. The measured Windows and Linux-Docker results are recorded in `blender-win32.json` and `blender-linux-docker.json`.
